C CONDITIONAL STATEMENTS - BASICS

• Conditional statements are used to make decisions in a C program.

• They help the program choose what to do depending on whether a condition is TRUE or FALSE.


1. IF STATEMENT

• The if statement is used when a block of code should execute only when a condition is true.

• Syntax:
  if (condition)

• If the condition is true, the statement executes.

• If the condition is false, the statement is skipped.


2. IF-ELSE STATEMENT

• Used when there are two possible choices.

• If the condition is true:
  - The if block is executed.

• If the condition is false:
  - The else block is executed.


3. ELSE-IF LADDER

• Used when there are multiple conditions to check.

• Conditions are checked one by one.

• When one condition becomes true:
  - The corresponding block is executed.
  - Remaining conditions are skipped.

• If none of the conditions are true:
  - The else block can be executed.


4. NESTED IF

• A nested if means using one if statement inside another if statement.

• It is used when one condition depends on another condition.

• Useful when multiple levels of checking are required.


5. SWITCH STATEMENT

• The switch statement is used when one variable can have multiple fixed choices.

• It is useful when checking one value against many possible options.

• Important keywords used in switch:
  - case
  - break
  - default

• case:
  - Represents a particular value.

• break:
  - Stops execution of the current case.

• default:
  - Executes when no case matches.


RELATIONAL OPERATORS

• Relational operators are used to compare values.

• >  → Greater than

• <  → Less than

• >= → Greater than or equal to

• <= → Less than or equal to

• == → Equal to

• != → Not equal to


LOGICAL OPERATORS

• Logical operators are used when more than one condition is involved.

• && → AND
  - Returns true only when both conditions are true.

• || → OR
  - Returns true when at least one condition is true.

• ! → NOT
  - Reverses the result of a condition.


IMPORTANT DIFFERENCE

• = → Assignment operator
  - Used to store a value.

• == → Comparison operator
  - Used to compare two values.

• Remember:
  - = means assign
  - == means compare


QUICK SUMMARY

• if
  - Used to check one condition.

• if-else
  - Used when there are two choices.

• else-if ladder
  - Used when there are multiple conditions.

• nested if
  - Used when one condition is inside another condition.

• switch
  - Used for multiple fixed choices.


IMPORTANT POINTS

• Conditions in C return either true or false.

• Zero is considered false.

• Any non-zero value is considered true.

• Curly brackets { } are used to group statements.

• break is commonly used in switch cases.

• default executes when no case matches.

• && means both conditions must be true.

• || means at least one condition must be true.

• ! reverses the condition.

• == is used for comparison.

• = is used for assignment.

• Conditional statements are very important for decision making in C.
